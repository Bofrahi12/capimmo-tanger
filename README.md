# سوق بيع العقار المغربي — v2

منصة مغربية (عربية RTL) للبحث ومقارنة العقارات المعروضة للبيع: فلاتر حقيقية، ثمن المتر المربع، «همزات» محسوبة حسابياً، مفضلة ومقارنة حتى 3 عقارات، حاسبة قرض سكني، ونموذج طلب عقار عبر واتساب (بدون إرسال تلقائي).

## التشغيل

الموقع **ثابت (Static)** — لا يحتاج خادماً ولا قاعدة بيانات:

- **الطريقة السريعة:** افتح `index.html` في المتصفح مباشرة.
- **الطريقة الأفضل (للنشر/الاختبار):** شغّل أي خادم ثابت من جذر المشروع، مثال:
  ```bash
  cd souq-alaqar
  python3 -m http.server 8080
  # ثم افتح http://localhost:8080
  ```
- **للنشر:** ارفع محتويات المجلد كما هي إلى أي استضافة ثابتة (Netlify / Vercel / GitHub Pages / cPanel).

> ⚠️ قبل النشر بدّل `https://example.com/` بالنطاق الحقيقي في: `index.html` و`listing.html` و`privacy.html` و`terms.html` (وسوم canonical وog) و`sitemap.xml` و`robots.txt`.

## تحديث العقارات

1. افتح `data/listings.js`.
2. أضف/عدّل/احذف عناصر مصفوفة `LISTINGS` فقط — كل الأقسام (البطاقات، الهمزات، الوكالة، الفلاتر، الإحصائيات، sitemap) تُبنى منها تلقائياً.
3. الصور الحقيقية توضع في `assets/` بصيغة WebP وتُذكر مساراتها في حقل `photos` مع `photo_real: true`. بدون صور حقيقية يظهر بديل توضيحي موسوم بوضوح «صورة توضيحية — لا توجد صورة للعقار».

### قواعد الصدق (إلزامية)

- لا تُضف عقاراً وهمياً على أنه حقيقي، والحقول المجهولة تبقى `null`.
- `verification`: ‏`page` = تم فتح رابط الإعلان فعلاً · ‏`index` = مرصود في نتائج البحث فقط · ‏`none` = لم يتم التحقق.
- ممنوع وصف العقارات بكلمة «موثق» — الصياغات المعتمدة: «تم التحقق من رابط الإعلان»، «آخر تحقق من التوفر»، «بيانات مأخوذة من المصدر الأصلي».
- «أقل بـX% من متوسط المدينة» نسبة محسوبة حسابياً، وليست تخفيضاً من البائع.

## المزايا

- 🔥 قسم «الهمزات»: ثمن المتر أقل من متوسط المدينة المرجعي — يُحسب تلقائياً.
- ❤️ مفضلة و⚖️ مقارنة حتى 3 عقارات (تُحفظ في المتصفح فقط).
- 📄 صفحة تفاصيل لكل عقار: معرض صور، المواصفات، شارات التحقق، رابط المصدر الأصلي، طلب معاينة/استفسار عبر واتساب، مشاركة، JSON-LD.
- 🧮 حاسبة قرض سكني مع تحقق من المدخلات وتكاليف تقديرية.
- 📩 نموذج طلب عقار يجهّز رسالة واتساب منظمة — **لا إرسال تلقائي أبداً**.
- 🌙 وضع داكن (تلقائي + زر تبديل)، 📱 متجاوب، ⌨️ دعم لوحة المفاتيح، `aria-live` لعدد النتائج، احترام `prefers-reduced-motion`.
